# Corporate Awards Voting (PHP)

Одностраничное PHP-приложение для весёлых корпоративных номинаций:

- Несколько корпоративов в одном файле данных: создавайте, переключайте и удаляйте проекты в админке.
- Быстрая загрузка списков номинаций и сотрудников (по строке на пункт) и очистка голосов.
- Голосование по QR-коду или ссылке: авто-подстановка участников через поиск.
- Полноэкранное шоу результатов: слайды «номинация» → «победитель» в стильном оформлении.

## Быстрый старт
1. Убедитесь, что установлен PHP 8+.
2. В корне проекта выполните:
   ```bash
   php -S 0.0.0.0:8000
   ```
3. Откройте страницы:
   - Админка: `http://localhost:8000/admin.php`
   - Голосование: `http://localhost:8000/vote.php`
   - Презентация: `http://localhost:8000/presentation.php`

## Формат данных
Данные лежат в `data/data.json` и создаются автоматически. Структура:
```json
{
  "version": 1,
  "active": "demo-party",
  "events": {
    "demo-party": {
      "id": "demo-party",
      "title": "Demo Corporate Party",
      "subtitle": "Sample data you can replace",
      "date": "2024-12-22",
      "nominations": ["Самый громкий смех"],
      "people": ["Анна Петрова"],
      "votes": [
        {"nomination": "Самый громкий смех", "person": "Анна Петрова", "timestamp": 1700000000}
      ]
    }
  }
}
```

## Подсказки
- Используйте разные события для отдельных корпоративов: QR-ссылка уже содержит `event`.
- На презентации есть управление кнопками «Назад/Далее» и автоматический переход (кнопка Play).
- Файл можно безопасно редактировать вручную, но удобнее через админку.
