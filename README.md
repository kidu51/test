# Корпоративные шуточные номинации

Простое PHP‑приложение для голосования за шуточные номинации на корпоративе.

## Страницы
- `index.php` — выбор раздела.
- `admin.php` — загрузка списков номинаций и сотрудников, QR‑код для голосования и просмотр результатов/слайдшоу победителей.
- `vote.php` — форма голосования с поиском по сотрудникам через выпадающий список.

## Запуск
Приложение не требует базы данных. Достаточно PHP 8+ и веб‑сервера, который может читать файлы из корня репозитория.

Пример запуска встроенного сервера:

```bash
php -S localhost:8000
```

После запуска:
- откройте `http://localhost:8000/admin.php`, чтобы загрузить списки номинаций и сотрудников;
- передайте QR или ссылку `http://localhost:8000/vote.php` коллегам для голосования;
- результаты и слайдшоу победителей доступны в админке.
