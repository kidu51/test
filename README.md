# Корпоративные шуточные номинации

PHP‑приложение для голосования за шуточные номинации на корпоративных проектах. Поддерживает несколько корпоративов, выдачу QR‑кодов, сбор голосов и полноэкранный показ результатов.

## Страницы
- `index.php` — посадочная с переходом в админку и голосование.
- `admin.php` — создание/удаление корпоративов, загрузка списков номинаций и сотрудников, QR‑код и ссылка на демонстрацию.
- `vote.php` — форма голосования с поиском сотрудников в выпадающем списке по каждому проекту.
- `presentation.php` — полноэкранный показ: сначала слайд с названием номинации, затем слайд с победителем.

## Запуск
Приложение не требует базы данных. Нужен PHP 8+ и веб‑сервер, который читает файлы из корня репозитория.

Пример запуска встроенного сервера:

```bash
php -S localhost:8000
```

После запуска:
- зайдите в `http://localhost:8000/admin.php`, создайте корпоратив и загрузите списки номинаций/сотрудников;
- передайте QR или ссылку `http://localhost:8000/vote.php?project=<ID>` коллегам для голосования;
- откройте `http://localhost:8000/presentation.php?project=<ID>`, чтобы показать результаты на весь экран.
